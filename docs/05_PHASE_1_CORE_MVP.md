# Phase 1 — Core Speaking MVP

## Goal
Create end-to-end speech conversation.

## Backend Tasks
- FastAPI project
- health endpoint
- Ollama provider
- Qwen model config
- session creation
- conversation endpoint
- SQLite persistence
- Docker support

## Android Tasks
- Kotlin Compose project
- Home screen
- Settings screen
- Configure backend URL
- Start session
- Record button
- Audio upload
- Show transcript
- Show AI response
- Android TTS

## Acceptance Test
1. Start backend.
2. Run Android app.
3. Tap Daily Practice.
4. Speak.
5. Transcript appears.
6. AI answers.
7. Device speaks AI response.
8. Conversation can continue for 10 turns.
