# Phase 2 — AI Tutor

## Goal
Turn chatbot into a tutor.

Tasks:
- Correction level setting
- Grammar correction
- Vocabulary improvement
- Natural alternative sentence
- Say-it-again flow
- Frequent error extraction
- Mistake history
- Daily lesson focus

Correction levels:
- none
- important
- aggressive

Acceptance:
- Important errors are stored.
- Repeated mistakes increment occurrence_count.
- App can show top recurring mistakes.
